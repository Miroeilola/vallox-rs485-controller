# Fonts

Inter 4.1 Regular (SIL Open Font License 1.1, see `OFL.txt`), pinned by
`Inter-Regular.ttf` in this directory (sha256 in the table below). The `.c`
tables here are generated by `tools/fontgen.py` and committed, so the firmware
and the host build never need Python:

    python3 tools/fontgen.py firmware/components/panel_ui/fonts/Inter-Regular.ttf \
        12 18 36 firmware/components/panel_ui/fonts

Sizes: 12 px (bars, captions), 18 px (lists, values), 36 px (the fan speed
and editor value). Glyph set: U+0020–U+007E, ä ö å Ä Ö Å (U+00E4 U+00F6 U+00E5
U+00C4 U+00D6 U+00C5) and ° (U+00B0). 4-bit alpha, two pixels per byte, high
nibble first; see `include/font.h`.

| File | Source | sha256 |
|---|---|---|
| Inter-Regular.ttf | https://github.com/rsms/inter/releases/tag/v4.1 | 40d692fce188e4471e2b3cba937be967878f631ad3ebbbdcd587687c7ebe0c82 |

Regeneration is deterministic for one Pillow version (generated with Pillow
12.1.1); CI does not regenerate. A look change (new size, new glyph) is a
regeneration committed in the same PR.
